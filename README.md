# Muhammad Dzaky — Web Developer Portfolio

Personal portfolio showcasing frontend engineering, intuitive UI/UX design, and expanding full-stack development.

## Tech Stack
- **Framework**: React 19 + Vite
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide React
- **Architecture**: Clean component-driven modular structure

## Getting Started

### Prerequisites
- Node.js (v18+ recommended)
- npm or pnpm

### Installation
```bash
npm install
```

### Running Locally
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### Production Build
```bash
npm run build
```
The optimized production output will be in the `dist/` directory.
